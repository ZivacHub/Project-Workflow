# Docs index
Every file in docs/ is listed here with WHEN to read it. A script checks that none is missing.

## Always (start of every session)
| File | What it is |
|---|---|
| ../CLAUDE.md | Rules, commands, stack for this project (short). |
| PRODUCT.md | The goal in the owner's own words. The compass. |
| plan/BOARD.md | Status board: what is done, what is next, and the change log. |
| DECISIONS.md | What the owner decided; open ones are at the top. |
| ../.claude/handoff.md | Where the last session stopped, numbered next steps, and the `Read first:` line. |

## For the current phase only
| File | Read when |
|---|---|
| plan/phases/NN-name.md | You work on that phase (one file per phase; read only the current one). |

## On demand
| File | Read when |
|---|---|
| reference/DESIGN.md | Changing how the page looks. |
| reference/TESTING.md | Writing or running checks, or deciding what "verified" means. |
| ../.claude/memory.md | Digging into recent history. |
